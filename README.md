THE WORLD TODAY — a dense newspaper front page summing up Friday 20 November 2026 in one image: 34 stories from every continent, led by Trump putting the Iran war decision off to 2027, plus a dotted world map marking where the news happened. compose.py draws the page with Pillow; main.ts copies the finished entry.png to the output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
